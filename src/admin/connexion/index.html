Mise en service de l’espace d’édition

Aucun compte n’est encore configuré. Choisissez un identifiant et un mot de passe : cette page calcule, dans votre navigateur, l’empreinte du mot de passe et une clé de session, à enregistrer dans les variables d’environnement du projet Vercel. Le mot de passe n’est envoyé nulle part.

Lettres minuscules, chiffres et tirets (ex. sandrine).

  1. Dans Vercel, ouvrez le projet → Settings → Environment Variables et ajoutez ces deux variables (environnement « Production », et « Preview » si besoin) : En local, ajoutez les mêmes lignes au fichier .env.local.
  2. Ajoutez aussi GITHUB_CONTENT_TOKEN (voir le README) pour que les articles puissent être enregistrés.
  3. Redéployez le site (Deployments → Redeploy), puis rechargez cette page.
  4. Pour ajouter une personne plus tard : générez sa ligne et ajoutez-la à ADMIN_USERS, séparée par une virgule.
